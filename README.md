# Newsfeed-Analysis-in-Tableau-Project

Newsfeed Analysis in Tableau

Overview

This project explores user engagement with the 365 platform’s Newsfeed feature using Tableau. The analysis covers interaction patterns, content performance, and user behavior, helping optimize the newsfeed for maximum engagement. The insights derived can improve user retention, course subscriptions, and platform activity.

Objective
	•	Analyze user interactions with the Newsfeed from January 1, 2023 – May 31, 2023.
	•	Compare automated vs. manual posts to determine which drives more engagement.
	•	Identify trends and areas for improvement in newsfeed functionality.
	•	Build interactive Tableau visualizations for data-driven recommendations.

Dataset Details

The dataset includes key metrics related to Newsfeed activity:
	•	post_id – Unique identifier for each newsfeed post.
	•	post_type – Indicates whether the post is automated (e.g., milestones, certificates) or manual (user-created content).
	•	timestamp – The date and time when the post was made.
	•	user_interactions – The number of likes, comments, or other engagements a post received.
	•	user_id – The identifier of the user interacting with the post.
	•	engagement_type – Specifies whether the interaction was a like, comment, or share.

Key Insights & Features

✅ User Engagement Trends – Identifying peak interaction periods.
✅ Post Performance Analysis – Comparing engagement levels of automated vs. manual posts.
✅ Interaction Type Breakdown – Examining how users engage (likes, comments, shares).
✅ Data Visualization in Tableau – Interactive dashboards for clear insights.

Project Structure
	•	Newsfeed_Analysis.twbx – Tableau workbook with visualizations.
	•	Dataset.csv – The raw dataset used for analysis.
	•	README.md – Project documentation.

How to Use This Project
	1.	Download the Dataset – Open Dataset.csv to review the raw data.
	2.	Open in Tableau – Load the dataset into Tableau and explore the Newsfeed_Analysis.twbx dashboard.
	3.	Analyze Engagement – Use filters and visualizations to uncover trends.
	4.	Draw Insights & Recommendations – Identify strategies to enhance Newsfeed performance.

Conclusion

This project provides data-driven insights into how users interact with the Newsfeed. By understanding engagement patterns, platforms can optimize content strategies to foster an active community, boost user retention, and increase course subscriptions. 🚀📊
